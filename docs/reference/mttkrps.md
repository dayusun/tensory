# Sequence of MTTKRP Calculations

Computes `mttkrp(x, U, k)` for all tensor modes.

## Usage

``` r
mttkrps(x, U, ...)
```

## Arguments

- x:

  A Tensor object.

- U:

  A list of factor matrices or a `KTensor`.

- ...:

  Additional arguments passed to methods.

## Value

A list of matrices, one per mode.
