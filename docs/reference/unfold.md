# Unfold Tensor

Unfold Tensor

## Usage

``` r
unfold(x, rdims = NULL, cdims = NULL, ...)
```

## Arguments

- x:

  A tensor-like object.

- rdims:

  Row modes.

- cdims:

  Column modes. If omitted, all remaining modes are used.

- ...:

  Additional arguments passed to methods.

## Value

A matrix.
