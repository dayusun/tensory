# Convert Tenmat to standard R vector

Convert Tenmat to standard R vector

## Usage

``` r
# S3 method for class 'Tenmat'
as.vector(x, mode = "any")
```

## Arguments

- x:

  A Tenmat object

- mode:

  The type of vector to be returned (e.g., "numeric", "character",
  "logical").

## Value

A vector
