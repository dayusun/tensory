# Transpose Tensor

Tensor transpose is not defined; use
[`permute()`](https://www.sundayu.me/tensory/reference/permute.md)
instead.

## Usage

``` r
transpose(x, ...)
```

## Arguments

- x:

  A Tensor object.

- ...:

  Additional arguments passed to methods.

## Value

This function always errors for tensors.
