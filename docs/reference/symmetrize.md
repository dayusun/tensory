# Symmetrize Tensor

Symmetrizes a tensor with respect to one or more mode groups.

## Usage

``` r
symmetrize(x, grps = NULL, ...)
```

## Arguments

- x:

  A Tensor object.

- grps:

  A vector of modes or list of mode vectors.

- ...:

  Additional arguments passed to methods.

## Value

A symmetrized Tensor object.
